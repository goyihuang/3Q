# 動物三國・無雙亂舞

用自家「動物版三國」角色圖做成的瀏覽器 3D 無雙動作遊戲。選一名武將，在戰場上以一擋千，擊破三名敵將後迎戰敵軍總大將。

**線上遊玩：** https://goyihuang.github.io/3Q/

## 操作
| 動作 | 鍵盤 | 手機 |
|---|---|---|
| 移動 | W A S D / 方向鍵 | 左下搖桿 |
| 普攻（4 段連擊，可長按） | J | 攻 |
| 蓄力攻擊 | K | 蓄 |
| 衝刺閃避 | 空白鍵 | 閃 |
| 無雙亂舞（量表滿時） | L | 無雙 |
| 暫停 / 靜音 | Esc / M | 右上按鈕 |

## 檔案
- `index.html`, `style.css`：畫面與介面
- `js/game.js`：遊戲本體（Three.js）
- `js/heroes.js`：**武將名稱、稱號、武器、數值都在這裡改**
- `assets/`：角色原圖（unit_hero_*、unit_army_*）

角色的立體感是程式依原圖輪廓「膨脹」成 3D 模型，完整保留原本的造型與上色。新增角色只要把 PNG 放進 `assets/`，再在 `heroes.js` 加一行即可。

不需要建置，任何靜態主機都能跑；本機測試可用 `python3 -m http.server`。
